# Canvas workspace overrides

The UI/UX Pro Max search informed interaction and accessibility rules. This is an embedded productivity workspace, so horizontal landing-page journeys and external font imports do not apply.

- White and warm paper surfaces; ink #17213B, cobalt #2855E8 primary, coral #FF7759, mint #D9F5E8, pale yellow secondary.
- Local system sans typography, 14px body, expressive 28–36px numbers, 24px section headings.
- 480px side dock; expandable 860px workspace; collapse to compact launcher. Never replace Canvas.
- Consistent SVG line icons. No emojis, marketing badges, fabricated grades, or synthetic account content.
- Clear source/status, refresh/progress, permission limitations, recoverable error and empty states.
- Keyboard focus, 44px controls where possible, reduced motion, AA contrast. Course/assignment links stay same-tab.
- No grades, credentials, or course content sent to external services. In-memory session data only.
